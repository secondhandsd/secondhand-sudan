# مستعمل السودان - Secondhand Sudan

منصة إلكترونية متخصصة لعرض وبيع وشراء المنتجات المستعملة في السودان.

## المميزات
* واجهة مستخدم بسيطة وسهلة.
* ربط مباشر بقاعدة البيانات لعرض المنتجات.
* تصميم متجاوب مع جميع الأجهزة.

## التقنيات المستخدمة
* HTML5
* CSS3
* JavaScript
* [اسم قاعدة البيانات التي استخدمتها - : Firebase

## رابط الموقع (Live Demo)
يمكنك تصفح الموقع مباشرة من خلال الرابط التالي : https://secondhandsd.github.io/secondhand-sudan

## كيفية التشغيل محلياً
إذا كنت مطوراً وتريد تجربة المشروع على جهازك:
1. قم بتحميل المشروع (Clone the repository).
2. افتح ملف `index.html` في أي متصفح.
